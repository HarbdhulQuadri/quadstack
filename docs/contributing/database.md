# Database Guide

QuadStack uses **Drizzle ORM** with PostgreSQL (Supabase recommended). All schema lives in `packages/db/src/schema.ts`.

## Rules

1. **Never edit `auth-schema.ts`** — it's auto-generated by Better Auth. Run `pnpm auth:generate` to regenerate it.
2. **Always export your tables** from `schema.ts` — the Drizzle client needs them all in one place.
3. **Use `pnpm db:push` in dev, migrations in prod** — push is fast but irreversible on column drops.

## Defining a table

```ts
// packages/db/src/schema.ts
import { boolean, integer, pgEnum, pgTable, text, timestamp, uuid } from "drizzle-orm/pg-core";
import { user } from "./auth-schema";

// ─── Enums ───────────────────────────────────────────────────────────────────
export const postStatusEnum = pgEnum("post_status", ["draft", "published", "archived"]);

// ─── Tables ──────────────────────────────────────────────────────────────────
export const post = pgTable("post", {
  id:        uuid("id").primaryKey().defaultRandom(),
  title:     text("title").notNull(),
  slug:      text("slug").notNull().unique(),
  content:   text("content"),
  status:    postStatusEnum("status").notNull().default("draft"),
  viewCount: integer("view_count").notNull().default(0),
  published: boolean("published").notNull().default(false),
  authorId:  text("author_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  createdAt: timestamp("created_at").notNull().defaultNow(),
  updatedAt: timestamp("updated_at").notNull().defaultNow().$onUpdate(() => new Date()),
});
```

## Common column types

| Type | Drizzle | SQL |
|---|---|---|
| UUID primary key | `uuid("id").primaryKey().defaultRandom()` | `UUID DEFAULT gen_random_uuid()` |
| Short text | `text("name").notNull()` | `TEXT NOT NULL` |
| Long text | `text("content")` | `TEXT` |
| Integer | `integer("count").notNull().default(0)` | `INTEGER NOT NULL DEFAULT 0` |
| Decimal | `numeric("amount", { precision: 12, scale: 2 })` | `NUMERIC(12,2)` |
| Boolean | `boolean("active").notNull().default(true)` | `BOOLEAN NOT NULL DEFAULT true` |
| Timestamp | `timestamp("created_at").notNull().defaultNow()` | `TIMESTAMPTZ NOT NULL DEFAULT NOW()` |
| JSON | `jsonb("metadata")` | `JSONB` |
| Enum | `myEnum("status").notNull().default("draft")` | `my_enum NOT NULL DEFAULT 'draft'` |
| Foreign key | `.references(() => user.id, { onDelete: "cascade" })` | `REFERENCES user(id) ON DELETE CASCADE` |

## Foreign key `onDelete` options

| Option | Behaviour |
|---|---|
| `"cascade"` | Deleting parent deletes child rows (most common) |
| `"set null"` | Deleting parent sets FK column to NULL |
| `"restrict"` | Prevent parent deletion if child rows exist |
| `"no action"` | Same as restrict (Postgres default) |

## Development workflow

```bash
# After editing schema.ts:
pnpm db:push        # Applies changes directly to the database

# Browse data visually:
pnpm db:studio      # Opens Drizzle Studio at http://localhost:4983
```

## Production workflow (migrations)

```bash
# Generate a SQL migration file (commit this to git)
pnpm db:generate

# Review the generated SQL in packages/db/drizzle/

# Apply to production database
pnpm db:migrate
```

## Adding indexes

```ts
import { index, uniqueIndex } from "drizzle-orm/pg-core";

export const post = pgTable("post", {
  id:       uuid("id").primaryKey().defaultRandom(),
  slug:     text("slug").notNull(),
  authorId: text("author_id").notNull().references(() => user.id),
}, (table) => [
  uniqueIndex("post_slug_idx").on(table.slug),
  index("post_author_idx").on(table.authorId),
]);
```

## Many-to-many relations

```ts
// Join table — no surrogate key, composite primary key
export const postTag = pgTable("post_tag", {
  postId: uuid("post_id").notNull().references(() => post.id, { onDelete: "cascade" }),
  tagId:  uuid("tag_id").notNull().references(() => tag.id, { onDelete: "cascade" }),
}, (table) => [
  primaryKey({ columns: [table.postId, table.tagId] }),
]);
```

## Querying across tables

```ts
import { eq } from "drizzle-orm";

// Join posts with their author
const postsWithAuthor = await db
  .select({
    id:         post.id,
    title:      post.title,
    authorName: user.name,
    authorEmail: user.email,
  })
  .from(post)
  .innerJoin(user, eq(post.authorId, user.id));

// Get all tags for a post via join table
const postWithTags = await db
  .select({ tag: tag })
  .from(postTag)
  .innerJoin(tag, eq(postTag.tagId, tag.id))
  .where(eq(postTag.postId, postId));
```
